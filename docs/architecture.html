System Architecture

Factory Inventory Management System

A full-stack demo for inventory tracking, order management, demand forecasting, and analytics. A Vue 3 single-page app talks over HTTP to a Python FastAPI service that serves validated data from in-memory JSON datasets — no database.

Request Data Flow

User adjusts a global filter

The FilterBar writes to the useFilters composable — a singleton holding period, location, category, and status shared across every view.

View requests data

The active view calls getCurrentFilters() and passes the result to a method on api.js, which builds a URLSearchParams query string (omitting any value equal to 'all').

HTTP call to FastAPI

Axios issues a request to http://localhost:8001/api/.... CORS (allow-all) permits the cross-port call from the Vite dev server on :3000.

Server filters in memory

The route handler runs apply_filters() (warehouse / category / status) and filter_by_month() (direct month or quarter via QUARTER_MAP) over the in-memory lists. Dashboard & reports endpoints additionally compute aggregates.

Pydantic validates & serializes

Results are validated against a response_model (e.g. InventoryItem, Order) and returned as JSON.

View renders reactively

The view stores raw data in refs; computed properties derive totals, groupings, and chart series, which render as tables and custom SVG charts.
